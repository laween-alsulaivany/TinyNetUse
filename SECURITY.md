# Security policy

## Supported versions

Security fixes are made for the latest released TinyNetUse version. Older releases may not receive separate fixes.

## Reporting a vulnerability

Do not report a suspected security vulnerability in a public issue or pull request.

Use GitHub's **Report a vulnerability** option in the repository Security tab:

https://github.com/laween-alsulaivany/TinyNetUse/security/advisories/new

Include:

- the affected TinyNetUse version;
- the Windows version and whether the installer or portable build was used;
- clear reproduction steps;
- the possible impact;
- any useful logs or proof-of-concept details without unrelated private data.

Please allow reasonable time to investigate and prepare a fix before sharing the vulnerability publicly. Reports made in good faith to improve TinyNetUse are welcome.
